# ChatSwiftly

> 🚧 **Work in Progress**  
> This project is actively being developed and is not yet complete.

## Overview
**ChatSwiftly** is a personal project aimed at building a web-based application where users can create accounts and communicate with each other in real time. The application focuses on seamless and secure communication with a modern interface.

## Technology Stack
This project utilizes the **PERN stack**, which includes:
- **PostgreSQL**: For database management.
- **Express.js**: As the web application framework for the backend.
- **React.js**: For building the user interface.
- **Node.js**: As the runtime environment for the backend.

### Development Tools
- **VSCode**: Used as the primary IDE for this project.
